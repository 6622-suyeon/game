# 수학 강화 학교

초등학교 5·6학년 수학 문제를 풀고 검을 강화하는 브라우저 게임입니다.

## 실행

추가 패키지나 API 키가 필요 없습니다. `index.html`을 브라우저에서 열거나 아래 명령으로 실행하세요.

```sh
cd /workspace/game
python3 -m http.server 8000 --bind 0.0.0.0
```

학년 선택 → 정답 입력 → 강화석 획득 → 강화하기 순서로 진행합니다. 분수는 `1/2`처럼 입력합니다. 강화는 100% 성공하며 5단계마다 검이 성장합니다. 진행 상황은 브라우저의 localStorage에 저장됩니다.

5학년: 약수, 최소공배수, 분수 덧셈, 직사각형 넓이.
6학년: 분수 나눗셈, 백분율, 직육면체 부피, 비례식.

## 추가된 성장 기능

- **오늘의 미션:** 새 문제에서 5개를 맞히면 강화석 3개를 자동 지급합니다. 학년 공통이며 브라우저의 현지 날짜 기준으로 매일 초기화됩니다.
- **연속 정답 보너스:** 새 문제에서 3연속 정답마다 강화석 1개를 추가 지급합니다. 새 문제 오답이나 학년 변경 시 연속 기록이 초기화됩니다.
- **오답 복습:** 틀린 문제를 학년별로 모아 다시 풀 수 있습니다. 정답을 맞히면 강화석 1개를 받고 목록에서 제거됩니다. 최대 100문제를 저장하며 초과 시 가장 오래된 문제부터 교체합니다. 복습은 미션과 연속 정답에 포함되지 않습니다.
- **성장 배지:** 첫 정답, 3연속 정답, 강화 +5, 복습 3개 해결, 정답 20개, 강화 +20 달성을 표시합니다.

기존 저장 기록은 유지되며 새 기능의 기록도 자동 저장됩니다. 초기화 버튼은 모든 기록을 지우므로 확인 창을 표시합니다.

## 검증

```sh
node --test --test-isolation=none tests/game.test.cjs
```

정적 HTML/CSS/JavaScript로 구성되어 별도 빌드가 필요 없습니다.

브라우저 통합 검증은 Playwright와 Chromium이 있는 환경에서 실행합니다. 기본 Chromium 경로는 `/usr/bin/chromium`이며 `CHROMIUM_PATH`로 변경할 수 있습니다.

```sh
node tests/browser.cjs
```

기존 저장 호환, 미션·연속 정답 보상, 중복 제출, 오답 복습, 날짜 변경, 모바일 화면과 초기화를 검증합니다.
