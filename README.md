# 수학 강화 학교

초등학교 5·6학년 수학 문제를 풀고 검을 강화하는 브라우저 게임입니다.

## 실행

추가 패키지나 API 키가 필요 없습니다. `index.html`을 브라우저에서 열거나 아래 명령으로 실행하세요.

```sh
cd /workspace/game
python3 -m http.server 8000 --bind 0.0.0.0
```

학년 선택 → 정답 입력 → 강화석 획득 → 강화하기 순서로 진행합니다. 분수는 `1/2`처럼 입력합니다. 강화는 100% 성공하며 5단계마다 검이 성장합니다. 진행 상황은 브라우저의 localStorage에 저장됩니다.

5학년: 약수, 최소공배수, 분수 덧셈, 직사각형 넓이.
6학년: 분수 나눗셈, 백분율, 직육면체 부피, 비례식.

## 추가된 성장 기능

- **오늘의 미션:** 새 문제에서 5개를 맞히면 강화석 3개를 자동 지급합니다. 학년 공통이며 브라우저의 현지 날짜 기준으로 매일 초기화됩니다.
- **연속 정답 보너스:** 새 문제에서 3연속 정답마다 강화석 1개를 추가 지급합니다. 새 문제 오답이나 학년 변경 시 연속 기록이 초기화됩니다.
- **오답 복습:** 틀린 문제를 학년별로 모아 다시 풀 수 있습니다. 정답을 맞히면 강화석 1개를 받고 목록에서 제거됩니다. 최대 100문제를 저장하며 초과 시 가장 오래된 문제부터 교체합니다. 복습은 미션과 연속 정답에 포함되지 않습니다.
- **성장 배지:** 첫 정답, 3연속 정답, 강화 +5, 복습 3개 해결, 정답 20개, 강화 +20 달성을 표시합니다.

기존 저장 기록은 유지되며 새 기능의 기록도 자동 저장됩니다. 초기화 버튼은 모든 기록을 지우므로 확인 창을 표시합니다.

## 검증

```sh
node --test --test-isolation=none tests/game.test.cjs
```

정적 HTML/CSS/JavaScript로 구성되어 별도 빌드가 필요 없습니다.

브라우저 통합 검증은 Playwright와 Chromium이 있는 환경에서 실행합니다. 기본 Chromium 경로는 `/usr/bin/chromium`이며 `CHROMIUM_PATH`로 변경할 수 있습니다.

```sh
node tests/browser.cjs
```

기존 저장 호환, 미션·연속 정답 보상, 중복 제출, 오답 복습, 날짜 변경, 모바일 화면과 초기화를 검증합니다.

## 수학 원정

새 문제의 정답으로 다섯 지역(새싹 숲 → 달빛 호수 → 수정 동굴 → 구름 성 → 별빛 정상)의 수호자 봉인을 풉니다. 오답이나 복습은 원정 진행을 줄이거나 늘리지 않으며, 시간 제한은 없습니다.

- 검 강화 5단계마다 정답당 봉인 해제량이 1 증가합니다(기본 1, 최대 5).
- 지역의 봉인은 순서대로 8·10·12·14·16입니다. 돌파하면 강화석 3·4·5·6·7개를 추가로 받습니다.
- 지역 첫 돌파마다 유물을 하나씩 모읍니다. 다섯 지역을 마치면 유물을 유지한 채 다음 원정이 시작됩니다.
- 진행은 학년 공통으로 자동 저장되며 기존 저장 기록도 유지됩니다. 처음부터 시작하면 원정과 유물도 초기화됩니다.

## 학습·편의 기능

- **단원 선택:** 각 학년의 네 단원을 골라 연습하거나 모든 단원을 섞을 수 있습니다. 학년을 바꾸면 전체 단원으로 돌아갑니다.
- **취약 단원 추천:** 아직 기록이 없는 단원을 먼저, 모든 단원에 기록이 있으면 새 문제 정답률이 낮은 단원을 추천합니다. 단원 변경 시 연속 정답은 초기화됩니다.
- **힌트:** 답 대신 풀이 방향을 알려 줍니다. 사용해도 보상은 줄지 않습니다.
- **경험치:** 새 문제와 복습 정답마다 10 XP, 50 XP마다 모험가 레벨이 오릅니다. 검 강화 레벨과는 별도입니다.
- **학습 기록:** 단원별 정답률은 업데이트 이후 새 문제만, 이번 접속 요약은 새 문제와 복습을 집계합니다. 예전 기록의 정답률을 추정해서 채우지 않습니다.
- **효과음:** 기본은 꺼짐이며 직접 켤 수 있습니다. 외부 음원 없이 브라우저에서 정답·오답·강화 소리를 만듭니다.
- **집중 화면:** 장식과 다른 패널을 숨기고 문제에 집중합니다. 효과음·집중 화면·선택 단원을 자동 저장합니다.
- **한 번에 강화:** 현재 강화석으로 다음 5단계 경계까지만 강화합니다. 부족하면 가진 강화석만 사용합니다.
- **백업·복원:** 성장 기록에서 JSON 백업을 다운로드하고 다른 기기에서 불러올 수 있습니다. 불러오기는 현재 기록을 바꾸기 전에 확인하며, 잘못된 파일을 읽으면 현재 기록을 유지합니다. 최대 파일 크기는 1MB입니다. 계정 동기화는 아닙니다.
- **입력과 접근성:** 전각 숫자와 ÷ 기호를 인식하고, 키보드로 문제에 바로 이동할 수 있습니다. 동작 줄이기 설정을 존중합니다.
